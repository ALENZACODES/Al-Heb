# Security

ALEF is a static Hebrew course in the private repository Al-Heb. Nothing is deployed.

## How to report

If you have access to this repository, report a vulnerability through [GitHub Security advisories](https://github.com/ALENZACODES/Al-Heb/security/advisories). If you cannot open an advisory, open a [GitHub issue](https://github.com/ALENZACODES/Al-Heb/issues) and say that it is a security report.

Do not include secrets, tokens, session data, or another person's private information in the report.

## Secrets

Do not commit secrets. A private repository is not a place for API keys, tokens, or passwords. If a secret has already been committed, treat it as exposed and rotate it.
