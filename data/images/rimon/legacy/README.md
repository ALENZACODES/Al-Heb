# Legacy Rimon stills (first overnight catalogue)

These stills were made against the first overnight pose list, whose numbers do not
match the Claude Lane A catalogue. They are kept so that work is not lost. The
app prefers `data/images/rimon/v2/` (Claude-order stills) and falls back to
`data/images/rimon/rimon-###.webp` for the earlier 001–125 set.

Stills 127, 135 and 138 from this first list were never accepted (holiday
accuracy or missing props) and are not here.
