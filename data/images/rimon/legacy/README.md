# Legacy Rimon stills (first overnight catalogue)

These stills were made against the first overnight pose list, whose numbers do not
match the 200-still catalogue (docs/images/RIMON-STILLS.md). They are kept so that work is not lost.
The app places the catalogue stills in `data/images/rimon/v2/` by meaning (src/shell/rimon-stage.js) and
matches the earlier numbered set `data/images/rimon/rimon-###.webp` to moments in tools/images/rimon/art-map.mjs.

Stills 127, 135 and 138 from this first list were never accepted (holiday
accuracy or missing props) and are not here.
