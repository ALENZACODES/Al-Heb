# Accessibility pass (lane 8, round 2, 2026-11-03)

Method: `node tools/a11y/run.mjs` (axe-core 4.14.0 installed with `npm install` in `tools/a11y/`, dev-only, MPL-2.0; see docs/TOOLING.md). axe is injected into every route in Chromium at 390x844 @2x, in light and dark colour schemes, on a profile that has completed lesson r01 (so lesson and review screens have content). Raw results: `tools/a11y/last-run.json`.
Scope limits: automated axe rules catch only a subset of problems; no screen reader (VoiceOver, TalkBack, NVDA) was used; no iOS/Android device was used.

## Found and fixed (shell, lane 1 views)
| Finding | Fix |
|---|---|
| Skip link `#main` was read by the hash router as route `/main` (not-found page) | click handler focuses `<main>` instead of navigating |
| On first load focus was pushed to the page heading, so the first Tab stop was not the skip link | focus is moved to the heading only on later navigations |
| Brand link `aria-label` ("ALEF home") did not contain its visible text | label is now "ALEF אלף, home" |
| Sound status bar was outside any landmark (axe `region`) | `role="region" aria-label="Sound status"` |
| Screens without an `<h1>` (letters detail, sounds, scan: other lanes' views) | shell adds a visually hidden `<h1>` from the route title when a view has none (views should still provide their own) |
| Learn: `tabpanel` role on an `<ol>` and `<li>` outside a list; tab roles without arrow-key support | track switch is two toggle buttons (`aria-pressed`), list has `aria-label` |
| Learn: locked lessons used `opacity` and failed contrast (98 nodes) | locked state uses the muted text colour and a dashed border |
| Learn: "Mark complete" button's accessible name did not contain its visible text | name is "Mark complete: <title>" |
| About: duplicate landmark names; tables did not fit 390px | per-entry lists instead of tables |
| Focus lost when a view re-rendered its heading | `replaceKeepingFocus` |

- first Tab stop is the skip link; Enter moves focus into `<main>`
- Tab order: skip link, brand, Home, Learn, Letters, Sounds, Read, Scan, Calendar, Settings, About, then page content
- focused nav link has a 3px solid outline
- Enter on the Learn nav link navigates and focus lands on the page heading
- Start button opens a lesson by keyboard; Listen works with Enter and updates the sound status; "Mark lesson complete" works with Space; "Review now" link works with Enter
