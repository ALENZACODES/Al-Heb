- `audioFree` (boolean, default false): the learner does not use audio. Hides Listen buttons, replaces listening-only questions with reading ones, never counts a skipped listening or speaking item. Owner lane: Deaf and hard-of-hearing. Code: src/shell/audiofree.js, row in src/shell/settings.view.js.
- `targetSize` ('normal' | 'large', default 'normal'): larger buttons, links and fields (CSS variable `--tap`, `data-target-size` on the root). Owner lane: motor and physical. Code: src/shell/motor.js, assets/css/app.css, row in src/shell/settings.view.js.
- `bottomActions` (boolean, default false): the main buttons of a screen stay at the bottom, within thumb reach (`data-bottom-actions` on the root). Owner lane: motor and physical.
- `untimed` (boolean, default false): no time limit anywhere. The Word Sprint has no clock and the Record and compare clip does not stop by itself. Owner lane: motor and physical.
- `confirmAnswers` (boolean, default false): choosing an answer only marks it; a "Check answer" button submits it. Owner lane: motor and physical.
- `keyShortcuts` (boolean, default true): false turns off the single-key shortcuts (1 to 4, S). Owner lane: motor and physical.
- `theme` (existing key, two new values): `'contrast'` (black on white) and `'contrast-dark'` (white on black) added to ENUMS.theme; labels `settings.theme.contrast` and `settings.theme.contrast-dark` in src/shell/i18n.js. No new key and no new store key. With `'auto'` the same palettes switch on when the device reports prefers-contrast: more. Owner lane: colour-blind and low contrast.
- `calmMode` (boolean, default false): turns off animation and motion (`data-calm` on the root), sound effects and vibration, hides streaks, timers and countdowns (Word Sprint and Timed read-aloud show no clock), shows the Today card as one next step with "More choices", and shows lessons in small parts. The system "reduce motion" choice is followed with or without it. Owner lane: cognitive, learning and sensory. Code: src/shell/comfort.js, assets/css/app.css, row in src/shell/settings.view.js.
- `shortSession` (boolean, default false): lessons come in small parts (a few items or questions each) and the place is saved after every part and every answer. Owner lane: cognitive. Code: src/curriculum/chunks.js, src/curriculum/lesson.parts.js. New store key `lesson.resume.v1` (row added in src/shell/privacy.view.js).
- `showStreak` (boolean, default true): false hides every streak line (Today card, Learn, Review summary, Progress, Morning). Nothing stored changes. Owner lane: cognitive.
- `readFont` ('default' | 'clear', default 'default'): 'clear' uses a system font stack (Verdana, Tahoma and similar; no download, no font file added). Owner lane: cognitive. CSS variable `--font-ui`.
- `lineSpacing` ('normal' | 'relaxed' | 'wide', default 'normal'): CSS variable `--line-height` (1.55, 1.8, 2.1). Owner lane: cognitive.
- `letterSpacing` ('normal' | 'wide' | 'wider', default 'normal'): CSS variable `--letter-spacing` (0.05em, 0.1em); Hebrew text is kept at normal spacing. Owner lane: cognitive.
- `textSize` ('normal' | 'large' | 'larger' | 'largest', default 'normal'): CSS variable `--text-scale` (1, 1.15, 1.3, 1.5) applied to the root font size, so it multiplies the browser's own text size. Owner lane: cognitive. (If another lane adds a text-size key, keep one of them.)
- `lineLength` ('normal' | 'narrow', default 'normal'): CSS variable `--measure` (46rem or 36rem) for the main column. Owner lane: cognitive.
