# Animation poses (DRAFT)

764 pose SVGs in 8 batches: 27 letters (7 poses each), 15 vowel and mark signs (5 poses each) and 100 everyday words (5 poses each, no Hebrew). Each item's poses share one path structure, so a player can morph one pose into the next. Contract: `docs/drafts/SUPER-COMMAND-ANIMATIONS-6H.md`.

Status: DRAFT, not reviewed by a designer or a native reader. Not used by the app, not in the offline cache, no route plays them. A structural check (same path count and commands per item, integer coordinates, no forbidden elements, title and description present) passed on all 142 items. The letter outlines are hand-traced polygons and some do not look like the printed letters; the middle poses of each morph are rough. `summary.json` lists a doubt for every item; nothing here is approved.
