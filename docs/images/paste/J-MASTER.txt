HOW TO RUN
1. Paste the files below one at a time, in this order: j-01.txt first, then j-02.txt, and so on. Each file is self-contained (style guide, rules, every prompt).
2. After each file, the tool replies with a numbered list of filenames and a count. Check the count matches, then say "next" and paste the following file.
3. Save every image under exactly the filename given (J-0001.png ... J-1000.png). Never rename. A browser suffix such as " (1)" is reported, never used.
4. Return the images by putting them all in one folder (for example ~/alef-returns/block-j) with their exact names. Do not add text, borders or captions to any image.
5. If an image comes out with any lettering, numerals or a real-looking face, regenerate that one image and keep the same name.

RULES THAT NEVER CHANGE: no text of any kind in any image, no real people or individual faces, no logos, aspect ratios only 1:1, 3:2 or 2:3 as shown on each item.
