# Rimon name options (for John and Claude — do not rename yet)

Updated 2026-11-10, 12:59 AM ET (America/Toronto).

John asked that no one should be able to tell whether the mascot is a boy, a girl, a man, or a woman. The name stays **Rimon** until John picks otherwise. This file only lists options and reasons.

The design stays frozen: round pomegranate-red body, gold three-point calyx, olive-green leaf ears, black oval eyes, pink blush, blue sash with a front bow (the bow is part of the existing sash, not a gendered accessory), tiny red arms and feet. No moustache, no extra bows, no clothing coded as masculine or feminine.

## Voice (already in force on this branch)

User-facing English and Hebrew about Rimon should not use he / she / him / her, or Hebrew gendered first-person forms that pin a sex on the mascot (for example not אֲנִי יוֹדֵעַ). Prefer the name "Rimon", an impersonal line, first-person wording that avoids a gendered verb, or a plural address to the learner (אַתֶּם is already used as a mixed-group "you").

## Options

### 1. Rimon (רִמּוֹן) — recommended keep

A pomegranate, which is the character. Used in Hebrew as a given name for more than one gender. Easy to say in English, already in the app, already tied to the fruit on the sash-and-calyx design. The noun is grammatically masculine in Hebrew, which is a mild caveat (like "apple" having a gender in other languages), but everyday use as a name is unisex. **No rename unless John wants one.**

### 2. Peri (פְּרִי)

Literally "fruit." Short, unisex as a modern Hebrew name, and on-theme without pointing at a sex. Very easy in English. Slightly more generic than Rimon (it could be any fruit). Spelling: Peri or Pri; Peri is clearer for English readers.

### 3. Nitzan (נִצָּן)

"Bud." A common unisex Hebrew name, and a clean metaphor for learning that is just starting to open. No built-in sex. A little less obviously tied to a pomegranate, and some English readers will need a pronunciation hint (nee-TSAHN).

### 4. Shai (שַׁי)

"Gift." Short, unisex, easy in both languages. Warm personality, but it is not visually about the fruit, so the mascot and the name would explain each other less well than Rimon or Peri.

### 5. Or (אוֹר)

"Light." Very short, used for more than one gender, easy to say. Risk: it is a tiny word and an English word, so it can disappear in a sentence ("or" / "Or"). Also not fruit-specific.

## Not recommended

- **Rimona** — the clearly feminine form of Rimon.
- **Names with a fixed "ben / bat" feel, or titles like Mr / Ms.**
- **Duo-like one-syllable animal nicknames** that copy the owl.

If a rename happens later, it should be a single coordinated pass across UI, speech, docs, and filenames, after John chooses.
