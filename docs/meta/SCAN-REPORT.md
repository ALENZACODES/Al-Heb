## Allowlist

When it appears, its `json-key` and `text-pattern` findings are reported as "allowlisted" and do not fail the scan, and `strip.mjs` skips it. The allowlist covers only those two kinds. Binary metadata in an image is never allowlisted by that entry.

## Strip tool

`tools/meta/strip.mjs` is a dry run by default. It prints the exact doc command for each file (exiftool for images and PDFs, ffmpeg `-map_metadata -1 -fflags +bitexact -write_id3v1 0 -id3v2_version 0` for audio).

`--apply` needs `--out DIR` or `--in-place`, and every stripped file is re-scanned before it replaces the original. In-place writes under `assets/images/incoming/` are refused unless `--allow-incoming` is given.

Without exiftool:
- PNG, JPEG, WebP and SVG are stripped by the built-in code, losslessly (chunks and segments are removed, pixels are untouched).
- PDF falls back to pypdf, which rewrites the file structure. Do not use that path on signed forms without a visual diff.
- Audio uses ffmpeg. The default is a lossless stream copy with tags removed. `--audio-mode reencode` uses the M.1 codec shape, `loudnorm -ac 1 -ar 44100 libmp3lame 96k`.
- JSON, CSV and HTML are never edited automatically, because replacing a field takes a human decision.
