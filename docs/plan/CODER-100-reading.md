# Coder 100: Reading Lane (12 November 2026)

Ideas B1 to B10 and G7 from the "100 coder-only ideas" brief. New screens live in `src/readlab/` (route `#/readlab` and
`#/readlab/<tool>`, loaded on first open; code and data are on demand, not in the first install). Store key `readlab.v1`.
Every read on these screens is self-reported; drill answers are checked against the app's own data, and nothing about speech
is measured. No new Hebrew was written: every word, family-letter set, verb pattern and stress mark is copied from existing data.
