## Sources

- Hebrew text: Unicode/XML Leningrad Codex (UXLC), Tanach.us Inc. — "All biblical Hebrew text, in any format, may be viewed or copied without restriction" (tanach.us/License.html). The text is not represented as the WLC. Per-book edition: Genesis UXLC 2.6, file dated 19 Oct 2026; Exodus UXLC 2.6, file dated 19 Oct 2026; Leviticus UXLC 2.6, file dated 19 Oct 2026; Numbers UXLC 2.6, file dated 19 Oct 2026; Deuteronomy UXLC 2.6, file dated 19 Oct 2026.
- English text: The Holy Scriptures: A New Translation (JPS 1917) — public domain (1917 US publication; digitisation via the Open Siddur Project / Sefaria). Fetched from the Sefaria v3 API with the version pinned by title; the response's version title and licence were asserted on every chapter. Newer JPS translations (1985, 2006, 2023) are CC-BY-NC on Sefaria and are never fetched.
- Verse division: the shipped grid is the standard Hebrew versification (the one printed Chumashim, Hebcal and this app's excerpt registry use). The UXLC's own WLC verse numbering differs in a few chapters (notably the Decalogue chapters, Exodus 20 and Deuteronomy 5, and the Numbers 25/26 chapter boundary). The UXLC word stream was re-grouped into standard verses using Sefaria's pinned Hebrew segments (the same UXLC text, re-segmented to the standard grid) as the guide, and the re-grouping is proven verse by verse: every shipped verse's consonant skeleton equals its guide segment's skeleton, and each book's word stream is consumed exactly. No character of the text was added, dropped or altered; only verse boundaries moved.
- Chapters where verse boundaries moved: Exodus 20; Numbers 26; Deuteronomy 5.
- Portion divisions (ranges and aliyot): Hebcal leyning data (@hebcal/leyning 5.2.0, https://unpkg.com/@hebcal/leyning@5.2.0/dist/index.mjs), the same source family the app calendar tables derive from (data/calendar/parsha.json, Hebcal-derived). Portion names (English + Hebrew) come from data/calendar/parsha.json, which holds 53 names (the Shabbat cycle); the 54th portion, Vezot Haberakhah, is read on Simchat Torah rather than a Shabbat, so its name is taken from the leyning data itself. All 54 ranges and all aliyot were validated by tiling against the standard verse grids: no gaps, no overlaps, Genesis 1:1 to Deuteronomy 34:12.
- Section breaks: petucha (open) and setuma (closed) markers come from the UXLC XML (<pe/> and <samekh/> elements) and are stored as a breakBefore flag on the following verse; a break that falls inside a verse is likewise recorded on the following verse.
- Display Hebrew is the house normalisation (src/corpus/normalize.js): pointed, cantillation stripped. heTrope keeps the cantillation as fetched (NFC).
