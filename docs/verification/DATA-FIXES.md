## C. FSRS: exact differences between `src/curriculum/srs.js` and FSRS-6 (not errors, the file says it is FSRS-style)

Reference: open-spaced-repetition wiki "The Algorithm", FSRS-6 section, fetched 2026-11-04. Default weights w0..w20 = 0.212, 1.2931, 2.3065, 8.2956, 6.4133, 0.8334, 3.0194, 0.001, 1.8722, 0.1666, 0.796, 1.4835, 0.0614, 0.2629, 1.6483, 0.6014, 1.8729, 0.5425, 0.0912, 0.0658, 0.1542.

| Element | srs.js | FSRS-6 | Effect |
|---|---|---|---|
| Forgetting curve | `(1 + (19/81) t/S)^-0.5` (FSRS-4.5) | `(1 + factor t/S)^-w20`, `factor = 0.9^(-1/w20) - 1`; default w20 = 0.1542, factor 0.9803 | R(2S): ours 0.825 vs 0.846; R(10S): ours 0.547 vs 0.693. At r = 0.8 the interval for S = 1 is 2.40 days (ours) vs 3.32 (FSRS-6). The 0.9 retention interval equals S in both. |
| Initial stability S0 (Again, Hard, Good, Easy) | 0.4, 1.2, 3.0, 8.0 | w0..w3 = 0.212, 1.2931, 2.3065, 8.2956 | Ours is higher for Again and Good. |
| Initial difficulty D0(g) | `clamp(5.5 - 1.1(g-3), 1, 10)` = 7.7, 6.6, 5.5, 4.4 | `w4 - e^(w5 (g-1)) + 1` = 6.413, 5.112, 2.118, -4.77 (clamped to 1) | Very different spread; FSRS-6 treats Good/Easy first reviews as much easier. |
| Difficulty update | `0.9 (D - 0.8 (g-3)) + 0.4` | `D' = D + (-w6 (g-3)) (10-D)/9`, then `w7 D0(4) + (1-w7) D'`, w6 = 3.0194, w7 = 0.001 (almost no mean reversion) | Linear damping toward 10 in FSRS-6; ours reverts 10% to 4 each review. |
| Stability after recall | `S (1 + e^1.6 (11-D) S^-0.2 (e^(0.9(1-R)) - 1) m)` | same shape with `e^w8` (e^1.8722), `S^-w9` (0.1666), `e^(w10 (1-R))` (w10 = 0.796) | Constants differ; shape matches the wiki formula. |
| Hard / Easy multipliers | 0.6 / 1.6 | w15 = 0.6014 / w16 = 1.8729 | Hard matches; Easy lower in ours. |
| Stability after lapse | `min(S, max(0.1, 0.3 S^0.7))`, D+1 | `w11 D^-w12 ((S+1)^w13 - 1) e^(w14 (1-R))` | Different form; FSRS-6 depends on D and R. |
| Same-day review | not modelled | `S e^(w17 (g-3+w18)) S^-w19` | absent |
| Fuzz, learning steps | none; Again = 10 min | present in implementations | by design |
| Illustration, four Good reviews at R = 0.9 starting from Good | stabilities 3.0, 9.18, 24.7, 59.8, 132.5 | 2.31, 11.9, 49.7, 174, 528 | Ours grows far more slowly. |

`srs.js` header text "FSRS-4.5/FSRS-5 curve ... FACTOR 19/81, DECAY -1/2" is accurate (wiki: "In FSRS-4.5, DECAY=-0.5 and FACTOR=19/81"). Note FSRS-5 also uses the 4.5 curve; only FSRS-6 introduces trainable decay. If the app should interoperate with Anki or use ts-fsrs 6.0.0, replace srs.js rather than tune it.
