# Vocabulary screen (`#/vocab`)

View: `src/vocab/vocab.view.js` (route already registered as optional in `src/shell/router.js`). Helpers: `model.js` (pure search/filter/card creation), `loader.js` (lazy tier loader), `split-tiers.mjs` (build tool).

## Data loading
`data/vocab/vocab5000.json` is 1.4 MB, so it is not split for size, but the screen does not read it. `node src/vocab/split-tiers.mjs` writes one file per tier band to `data/vocab/packs/vocab5k-tier-{500,1000,2000,5000}.json` (95 KB, 90 KB, 178 KB, 534 KB after the round-2 fields tags/fn/forms were added). `data/vocab/packs/` is skipped by `tools/build-precache.mjs`, so these are fetched when a tier is opened and cached at runtime by sw.js. Only the selected tier loads (default: words 1-500); "All 5,000 words" loads all four. `tests/vocab.view.test.js` fails if the packs are stale (`--check` does the same from the command line). Note: `vocab5000.json` itself is still precached by the existing rules (under 2 MiB); that is a shell/build decision, not changed here.

## Browse
Tier select, topic select (topics come from the loaded tier's content words; a last option "Function words (no topic)" is the group for closed-class words, which are never shown under Misc Nouns), "Kind of word" select (tag filter: prayer, jewish-life, function words, biblical, colloquial; these tags are heuristic gloss-keyword tags), a "Show word forms" checkbox, and a search box. Entries with `isForm` are hidden unless that box is ticked; when shown they carry "This is a form of another word" with a button to the main word (the button reloads Browse with all tiers and a search for it). Round-2 fields shown on a card: `forms[]` on function words ("Forms (from Wiktionary, may be incomplete)", exact duplicates removed, unpointed where Wiktionary had no pointing), a visible "needs check" badge, a "Rare sense" or "Homograph" hint line, and "Also spelled the same: ..." from `sameSpelling` (resolved only against tiers already loaded; others are counted as "N more in other tiers"). Function-word cards show "function word (sub-type)" instead of the placeholder topic. Only `pointed` is displayed when present (the lemma spelling is used for display only when there are no vowel points, and in search); form and cross-reference labels use `pointed` too. Search: input containing Hebrew letters matches lemma or pointed form after removing vowel points and cantillation (pointed and unpointed queries both work); anything else matches the English gloss, case-insensitive. Cards show pointed Hebrew (`lang="he" dir="rtl"`), gloss, part of speech, topic, frequency rank, and a siddur-style transliteration from `src/pronunciation/transliterate.js` for the learner's `congregation` setting (labelled approximate; empty for the 2 words without vowel points). 40 cards per page ("Show N more" moves focus to the first new card).

## Audio
If `ctx.audio.has('word', id)` is true the recording is played (`ctx.audio.play`). No vocabulary ids are in the audio manifest today, so in practice every button is the browser's Hebrew voice (Web Speech `he-IL`), labelled "Listen (computer voice)". After playing, a polite live region says it is a computer voice, not a recording, that it reads Israeli pronunciation (not Sephardi/Ashkenazi if that is the setting), and may ignore vowel points. No Hebrew voice or no speech synthesis gives a plain "No sound" message.

## Review
Per word or per filtered set (up to 100 words per click; the set button skips `isForm` and `rare-sense` entries and says how many it skipped, a card's own button still adds that card) "Add to reviews" creates SRS cards (`newCard` from `src/curriculum/srs.js`, id `vocab:<id>`, plus `tier` and `topic`) in store key **`srs.vocab`**. They are deliberately not in `srs.cards`: the lesson review queue and home screen understand only letter/vowel/lesson-word ids, so mixing them would inflate the home "due" count with cards that screen cannot show. Consequence: the home screen does not count vocabulary reviews (`src/shell/home.view.js` line ~54 counts `srs.cards` only; adding `srs.vocab` there is a change in a file this screen does not own, and it was NOT made, since Home's Review link opens the lesson queue that cannot show vocab cards); the Review button here shows its own due count. Session: up to 20 due cards, Hebrew first, "Show answer", then Again/Hard/Good/Easy (keys 1-4 after the answer is shown), scheduling by `review()` in srs.js. A word rated Again is shown once more in the same session. Deep link: `#/vocab?review=1`.

## Accessibility
One `h1` (focus target on navigation). Every control has a visible `label`. Mode buttons use `aria-pressed`. Result counts, audio notes and answers are in polite live regions. 48 px minimum targets for selects/inputs and buttons use the shared `.btn`. In review, focus moves to the card, then to the answer after "Show answer". Hebrew is always `dir="rtl"`. Not tested: a real screen reader, keyboard walk-through in a real browser, forced-colors, or reduced-motion (no motion is used).

## Known gap (round 2)
The tier packs written by `split-tiers.mjs` do not include `sameSpelling` (its KEEP list has isForm/formOf/formIds/forms/tags/fn but not sameSpelling), so in the running app the "Also spelled the same" line does not appear yet. The view supports it and the test feeds it the full file. Fix: add `'sameSpelling'` to KEEP and regenerate the packs (a few tens of KB).
