# Recording script: Israeli (Modern Hebrew)

Generated by tools/audio/recording_script.mjs from data/audio/manifest.json. Do not edit by hand; re-run the tool.

Only the human-only clips are listed below: letter names, isolated sounds, vowels and syllables. Words, lines, phrases and prayers already have synthetic clips, so they are not requested here.

## How to use

- Record each voice talent (m = man, f = woman) separately. File name = path below under `audio/<voice>/`; i.e. the full path is `audio/m/israeli/<kind>/<id>.mp3` and `audio/f/...`.
- Deliver 48 kHz / 24-bit WAV masters named like the path (`<id>.wav`), one file per clip, plus the CSV filled in. Lane tooling will normalize and encode (tools/audio/normalize.sh).
- Record the take count shown for every clip and mark the preferred take; keep head/tail silence of about 0.3-0.5 s.
- Pointed Hebrew is the authority for what to say. IPA is shown only where the project data supplies it (lane-4 starter values for Israeli syllables and consonants; NOT native-checked).
