# Extra printable sets: First 10 minutes, cursive words, niqqud (DRAFT, unreviewed)

Three generators next to `tools/letters/workbook.mjs` (which was not edited). Each writes A4 and US Letter PDFs to `docs/workbook/`, the HTML source to `docs/workbook/html/`, copies the PDFs to `assets/workbook/`, merges its entries into `assets/workbook/manifest.json` and rewrites `docs/workbook/index.html`. Every PDF is scrubbed by `book/pdf_tools.py scrub` (metadata = Author "John Khan" only). Dev tooling only: Playwright Chromium for the PDF step; the model and HTML functions are pure and tested in `tests/workbook.firstday.test.js`.

`--html-only` on any tool skips Chromium and writes only the HTML (no manifest change).

## Manifest and index

- `assets/workbook/manifest.json`: entries carry `kind` (`firstday`, `cursive-words`, `niqqud`) and a readable `script` label, because `src/shell/workbook.view.js` (not edited) prints `LABEL[f.script] ?? f.script`; the app therefore lists them as "First 10 minutes, A4" and so on. `bytes` is re-read from disk at merge time; `tests/integration.test.js` checks the sizes.
- `docs/workbook/manifest.json` is **not** touched: `tests/letters.workbook.test.js` requires exactly 4 or 8 entries there, all of the `alef-workbook-*` shape.
- `docs/workbook/index.html`: one page listing every PDF in the asset manifest (both the main workbook and these sets) with pages and sizes. Regenerated by any of the three tools; `writeIndexPage()` in `firstday_pages.mjs`.
- Order of builds matters once: `node tools/letters/workbook.mjs` (the main tool) rewrites `assets/workbook/manifest.json` with only its own 4 or 8 entries, dropping these. After a main rebuild, re-run the three tools above (each merge keeps the others' entries).
- `precache-manifest.js` was not rebuilt (PDFs under `assets/workbook/` are excluded from precache anyway).

## Book hook

`book/firstday/section.mjs` builds the chapter "Your first 10 minutes" (plan table, letters, vowels, words, the 20-step ladder as a table, draft flag). `book/build.mjs` changed by 4 lines: the import, `${firstDayChapter(pages)}` after the class-track section (before the pronunciation traditions page), one contents line and one index line (both `FIRSTDAY_ID` / `FIRSTDAY_TITLE`). `scrubPdf` in the book build is unchanged.

## Status

Draft everywhere: stroke order, pointing, glosses and example words are not reviewed by a Hebrew teacher; Israeli pronunciation only; not tested with learners. Each page carries this in the footer and the front page of each set repeats it. Transliterations marked `*` are machine-made (`src/pronunciation/transliterate.js`, siddur scheme). Fonts: Frank Ruhl Libre (print) and Gveret Levin (cursive), SIL OFL 1.1.


## Build everything: `node tools/letters/build_all_workbooks.mjs`

Runs every tool, scrubs every PDF in `docs/workbook/` and `assets/workbook/` (Author "John Khan" only), then rebuilds `assets/workbook/manifest.json` and `docs/workbook/index.html` from the PDFs on disk with `tools/letters/workbook_manifest.mjs`. Flags: `--html-only`, `--skip-core` (keep the 8 main `alef-workbook-*` PDFs), `--skip-cards` (skip the flashcards, about a minute), `--no-mnemonics`.

The manifest problem is fixed: `workbook.mjs` still overwrites the asset manifest when run alone, but `node tools/letters/workbook_manifest.mjs` restores it (core entries from `docs/workbook/manifest.json`, extra sets from the sidecar `docs/workbook/extras-manifest.json`, sizes and page counts read from the PDFs). Each extra tool calls it automatically.
